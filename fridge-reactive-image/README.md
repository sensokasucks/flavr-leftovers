# Fridge Reactive Image

Native Python audio-reactive avatar for XSplit / OBS.

Scrollable settings UI, custom hold/toggle states + hotkeys (pynput), HTTP control on port 3851, optional serial for tablet/Arduino.

## Quick start

```bat
build.bat
```

Or:

```bash
pip install -r requirements.txt
python reactive_image.py
```

Control endpoint: `http://127.0.0.1:3851`
