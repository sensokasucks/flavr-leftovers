        Core
        
HTTP server that serves overlays, admin, and APIs. Leave host on 127.0.0.1 unless you know you need LAN access.

        
        
        
        
      


      

        Kick
        
Public chat socket + viewer poll. Chatroom id is auto-detected and saved when possible.

        
        
        
      


      

        Twitch
        
Read-only anonymous IRC — no OAuth needed to listen.

        
        
      


      

        YouTube
        
Live chat reader. innertube needs the live video id each stream; official mode needs an API key.

        
        
        
        
      


      

        Minecraft
        
Talks to the Fabric client/server mods. Turning this off also disables the minecraft command group (!spawn, !give, …).

        
        
        
        
      


      

        Permissions
        
One username per line. Matched case-insensitively across every platform.

        
        
      


      

        Chat points
        
In-house points for chatting. Off by default. When on, enables the points command group (!points). Admin token unlocks this dashboard.

        
        
        
        
      


      

        Chat history log
        
Writes every message to SQLite for this dashboard's Chat History tab and CSV export. The live overlay does not need this. Off by default.
