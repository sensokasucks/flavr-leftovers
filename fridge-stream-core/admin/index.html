      Permissions, points + chat
      
    
    
    
      
    
        Permissions
        
    One person per line, upper/lower case doesn't matter. Best: say the platform, like kick:name or twitch:name. A plain name counts on Kick and Twitch, but when both are on it only counts where it's your own channel name (someone else could take that name on the other platform). YouTube needs youtube: + the channel id (UC…).
    
        
        
      
    

      
    
        Chat points
        
    In-house points for chatting. Off by default. When on, enables the points command group (!points). Admin token unlocks this dashboard.
    
        
        
        
        
        
        
        
        
    
      
    

      
    
        Chat credits
