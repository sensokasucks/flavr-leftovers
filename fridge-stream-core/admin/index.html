      Core + chat platforms
      
    
    
    
      
    
        Core
        
    HTTP server that serves overlays, admin, and APIs. Leave host on 127.0.0.1 unless you know you need LAN access.
    
        
        
        
        
      
    

      
    
        Kick
        
    Public chat socket + viewer poll. Chatroom id is auto-detected and saved when possible.
    
        
        
        
        
      
    

      
    
        Twitch
        
    Chat is read without a login. Connect your Twitch account for chatter profile pictures.

      Games
      
    
    
    
      
    
        Minecraft
        
    Talks to the Fabric client/server mods. Turning this off also disables the minecraft command group (!spawn, !give, …).
    
        
        
        
        
        
    Stock / vault rates live on the Market tab so they stay together.
    
      
    

      
    
        Factorio
        
    
          Talks to the Fridge Factorio Stats bridge (RCON + overlay on port 3847).
          Enable this so Factorio shows on Status and Integrations. The Node bridge
          is still a separate process.
        
    
        
        
      
    

      
    
        Granvir
        
    
          Talks to Fridge Granvir Stats (BepInEx plugin or mock server on port 3855).
          Enable this so Granvir shows on Status and Integrations. Co-op writes stay
          host-only inside the plugin.
        
    
        
        
      
    

      
    
        OpenTTD
        
    
          Admin Port (default 3977) on a vanilla or JGRPP server.
          Chat funds companies with !invest. Copy
          gamescripts/FridgeChatFund into OpenTTD’s game folder
          so investments become in-game cash.
