      Phone remote
      
      
      Use your phone as a remote for the Live controls over your home Wi-Fi: highlight chat,
        roll the credits, open the curtain, give points and red-flag chatters. Settings, sign-ins and files stay on this PC.
        Only phones you pair here can use it.
      
    
      
    
      
      Switch it on
      
      
      —
      
      
      
      
      The first time, Windows asks whether Python may use the network. Tick Private networks
        only (not Public) and press Allow. The phone must be on the same Wi-Fi as this PC; a guest network usually can't see it.
      
      
      
      
        Advanced
        
        
      If the address changes after a router restart, pair-by-address stops working until you scan again. To stop that,
          "reserve" this PC's address in your router's settings (often called DHCP reservation).

      Read aloud (TTS)
      
      
      Have alerts, paid messages, !tts and chosen chat lines read aloud on stream.
        Stream Core doesn't include a voice: it sends the text to your own text-to-speech server
        (Kokoro-FastAPI, AllTalk, a Chatterbox server, openedai-speech… or a paid cloud service) that answers

        Chat smoothing
        
      YouTube chat arrives in clumps, one each time Core checks. Smoothing holds a platform's chat for a moment and lets it out at an even pace, so overlays, Stream Rooms and the credits show a steady flow. Kick and Twitch send each line the moment it is typed, so they rarely need it. A line a mod deletes while it waits is never shown.
